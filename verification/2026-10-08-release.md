# Initial collection release verification — 2026-10-08

## Scope

Moved `opencode-orchestration` into `skills/` and introduced repository-wide
versioning through `VERSION`, `CHANGELOG.md`, and `RELEASE.md`. Initial version:
`0.1.0`. Publication is limited to the repository commit and annotated Git tag.

SHA-256 inventory comparison confirmed all nine source files survived the move
unchanged. Four agent example headings were then added to satisfy this repository's
Markdown rules. The source folder was removed by the move; the original application's
pre-existing configuration modification was preserved. No skills were installed or
agent configurations activated.

## Checks performed

- Unique YAML keys, supported skill metadata, name/directory agreement, description
  constraints, inactive model markers, and repository-local Markdown links passed.
- `VERSION` and the changelog agree on `0.1.0`.
- `skills` CLI 1.7.1 in list mode discovered both `opencode-skill-author` and
  `opencode-orchestration` without installing either.
- `markdownlint-cli2` 0.23.3 passed after adding the four headings.
- The exact Bash release block in `RELEASE.md` was exercised in a disposable local
  repository with a bare remote. It rejected a dirty tree while preserving an
  unrelated file, atomically pushed the branch and annotated tag, resolved matching
  remote commit refs, and rejected reuse of the local tag. Temporary repositories
  were removed afterward.

The release procedure deliberately uses explicit version selection and Conventional
Commits; it does not install hooks, automatically calculate versions, create GitHub
Releases, or publish packages/assets. CLI versions are pinned in the documented
commands, without adding application dependencies or a package manifest.

## Coverage limits

This release adds packaging and release-process evidence. It does not establish live
OpenCode execution, effective provider permissions, or behavior of the three target
models. Earlier tabletop and authoring checks remain documented with each skill.
No application test suite is applicable to this collection-only change.
