# corp-skills

Коллекция навыков в формате Agent Skills, совместимая с `npx skills` и OpenCode.

## Доступные навыки

| Навык | Назначение |
| --- | --- |
| [opencode-skill-author](skills/opencode-skill-author/SKILL.md) | Создание и адаптация навыков для DeepSeek-V4.1-Flash, GLM-5.3 и Qwen3.8-27B; отдельные рекомендации по задачам и проверке. |
| [opencode-orchestration](skills/opencode-orchestration/SKILL.md) | Оркестрация Python/ML: DeepSeek для координации и реализации, GLM для независимой проверки и сложной инженерной работы, необязательный Qwen для визуального анализа. |
| [cveta2](skills/cveta2/SKILL.md) | Работа с CVAT: выгрузка и загрузка разметки, конвертация датасетов, метки, кэш и проверка результатов. |
| [clearml-yolo](skills/clearml-yolo/SKILL.md) | Запуск и проверка обучения, предсказаний, метрик и сравнения моделей через Hydra; ClearML, конфигурация и отдельная очередь GPU. |

## Просмотр и установка

Нужны Node.js с `npx`, Git и доступ к этому приватному репозиторию через GitHub SSH.
Проверить список навыков без установки:

```bash
npx --yes skills@1.7.1 add git@github.com:BuckanovNikita/corp-skills.git --list
```

Установить выбранный навык для OpenCode в текущий проект:

```bash
npx --yes skills@1.7.1 add git@github.com:BuckanovNikita/corp-skills.git \
  --skill opencode-skill-author --agent opencode
```

Для глобальной установки добавьте `--global`. Установка навыка не настраивает
провайдера, модель или права инструментов OpenCode.
Для навыка оркестрации замените имя после `--skill` на `opencode-orchestration`.
Для работы с инструментами используйте `--skill cveta2` или `--skill clearml-yolo`.
Каждый пакет устанавливается отдельно и содержит собственные примеры и проверки.
Примеры агентов в его каталоге `examples/agents/` не активируются автоматически:
перед отдельным подключением укажите доступные идентификаторы моделей и проверьте
[совместимость конфигурации](skills/opencode-orchestration/references/opencode-setup.md).

## Использование

По умолчанию выберите **DeepSeek-V4.1-Flash** для планирования, исследования,
реализации и создания навыков. **GLM-5.3** добавляет независимую проверку или
альтернативный подход к сложной инженерной задаче. **Qwen3.8-27B** необязателен:
используйте его для анализа изображений и ограниченных задач, когда пригодность
подтверждена. Можно работать одной моделью, сохраняя отдельную свежую сессию
проверки. Использование всех трёх моделей не является требованием.

Для существенных рассуждений используйте thinking и проверенный максимальный
уровень: `max` для DeepSeek/GLM, `xhigh` для Qwen. Настройки зависят от адаптера;
текст навыка их не включает. Цена и расход токенов не служат основанием для снижения
качества. Выбор ролей — предварительная инженерная рекомендация, а не доказанная
победа в каждой задаче: [основания и ограничения](skills/opencode-orchestration/references/model-selection-2026-10-20.md).

Публично подтверждённая октябрьская версия DeepSeek — **V4.1-Flash-1017**.
Написание `0117` требует уточнения; псевдоним API `deepseek-flash` не является
неизменяемым идентификатором версии. Перед подключением примеров проверьте точные
provider/model ID, поддержку изображений, инструментов и режима рассуждений.

Для начала с планирования выберите встроенный агент **Plan** и задайте
`default_agent: "plan"`. Модель и режим агента настраиваются отдельно.
[Неактивный пример конфигурации](skills/opencode-orchestration/examples/opencode.plan.json)
показывает выбор модели и стартового агента Plan; перед подключением замените
идентификаторы-заглушки и проверьте существующие настройки.
[Порядок перехода к реализации](skills/opencode-orchestration/references/opencode-setup.md#start-in-plan)
сохраняет выбранную модель и разрешает запись только после выхода из Plan и
авторизации выполнения. Навык не переключает режим и не устанавливает конфигурацию.

После перехода к разрешённому выполнению можно попросить:

```text
Use opencode-skill-author to create a standalone skill that reviews CSV quality
against a supplied schema and writes a Markdown report. Do not install it.
```

Примеры запросов к навыкам инструментов:

```text
Use cveta2 to export project 123 to a new directory without images or ClearML
publication. Check the CSV outputs and report partial results.

Use clearml-yolo to prepare a training configuration for my ground_truth.csv.
Inspect the schema and compose the config; do not launch training yet.
```

При добавлении возможностей в инструменты их этап обновления документации
требует проверить и обновить соответствующий навык. Канонические пути, порядок
проверки и обработка недоступного репозитория описаны в
[MAINTENANCE.md](MAINTENANCE.md). Проверки этой версии и ограничения исполнения
на целевой модели — в [отчёте](verification/2026-10-14-tool-usage.md).

Рекомендации для моделей и сценарии проверки находятся в каталоге навыка.
Границы первоначальных проверок описаны в
[отчёте](skills/opencode-skill-author/evaluation-2026-10-08.md): совместимость
упаковки не означает проверку поведения на реальных целевых моделях.
Проверки обновлённого выбора моделей и запуска с Plan описаны в
[историческом отчёте от 2026-10-11](verification/2026-10-11-model-selection.md).
Обновление набора моделей, сценарии и границы проверки описаны в
[отчёте от 2026-10-20](verification/2026-10-20-opencode-model-routing.md).

## Проверка локальной копии

Из корня репозитория:

```bash
DISABLE_TELEMETRY=1 npx --yes skills@1.7.1 add . --list
npx --yes markdownlint-cli2@0.23.3 '*.md' 'skills/**/*.md' 'verification/**/*.md' 'docs/**/*.md'
```

Если репозиторий недоступен, проверьте права GitHub и SSH-аутентификацию. Если
навык не появляется в OpenCode, проверьте каталог установки и разрешения
`permission.skill` в конфигурации OpenCode.

## Версии

Коллекция версионируется целиком по Semantic Versioning. Версия содержимого указана
в [VERSION](VERSION), изменения — в [CHANGELOG.md](CHANGELOG.md). Опубликованные
версии отмечаются аннотированными Git-тегами `vMAJOR.MINOR.PATCH`; пакеты и файлы
релизов не публикуются. Для воспроизводимой копии используйте checkout нужного тега.
Порядок проверки и выпуска описан в [RELEASE.md](RELEASE.md).
